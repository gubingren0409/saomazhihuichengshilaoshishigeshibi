# PG1 地图信息完整性审计

G1 状态：等待用户自然语言地图审核。以下是作者审计结果；独立复核、GPT 审核与用户接受分别登记。当前成果不表示整个 Parent Goal 通过。

六个冻结裁片逐场景顺序读取，没有调用新地图 API、没有下载地图、没有重跑历史请求，也没有构造完整可视图或执行路径搜索。历史路线直接读取真实结果 JSON，逐文件 SHA256 对照 `formal_registry.jsonl`；页面中的“历史结果”切换只展示原有输入和输出。

## 实际发现

1. 六裁片合计 306,927 个源对象记录（跨裁片存在大量重复，不是独立样本数）。53,624 个对象有供审核显示的真实源几何；无标签节点作为拓扑坐标保留，不逐个绘成 POI。
2. 8,025 个机动车道路源对象均保留为适配器的地图上下文，也均在旧诊断视图中有对应几何。不能把“没有成为人行边”解释成道路被导入或渲染删除。
3. 旧渲染的道路为灰色 1.8px 线，缺少道路名称和等级标注。新审核图显示原名、视觉道路等级，并允许点选原始 highway、name、foot、sidewalk、access 等标签。这里的线宽是显示样式，不是车行道实测宽度。
4. 六裁片没有 `area:highway` 道路面，也没有 `area=yes` 的机动车道路面。原始几何只支持中心线的地方没有补造道路面。道路轴上 `sidewalk` 标签与独立 `footway=sidewalk` 几何分列，不能据标签创造两侧人行道或新的过街位置。
5. 冻结原生段准入规则的只读回放得到 30,420 个保留线段。回放只调用历史 `_segments` 和 `segment_decision`，未调用图构建、求路或可视图生成。8,025个机动车道路对象中，4,272个有至少一段通过旧准入规则；这些道路轴可能依赖 `SHARED_STREET_ASSUMPTION`、`SIDEWALK_TAG_WAY_AXIS` 或显式 foot 标签，不等于独立人行道或已确认现实可走。C用紫色虚线区分准入道路轴与蓝色人行源线，不改变旧准入科学方法。
6. 武康大楼与展览中心的冻结 R4 面边文件为空；图上 C 显示的是本轮明确标记的原生准入回放及旧合法面，不宣称已有历史全局路由图。其余裁片的冻结面边数量见机器清单，它们是旧 R4 的 3m 面边带，不能冒称完整面内可视图。
7. 博物馆和图书馆有原登记门及真实历史 APP 路线。其余四场景无原登记门、本轮无对应 APP 路线；未生成代理门、起点或路线。

## 如何核对

- `index.html`：六场景、四视图同尺度、图层开关、联动缩放/拖动、街区/完整裁片/局部切换、对象点选和自然语言审核记录导出。
- `maps/<scene>.png` 与 `.svg`：六张固定四层对照图。D 是旧 R1 绘制策略的同尺度复现与真实历史路线，明确不是本轮打开旧应用得到的截图。
- `data/<scene>/object_lineage.jsonl.gz`：每个原始 ID 的 raw/import/routing/render 四层记录。逐阶段记录标签是否保留；上下文未接收某对象的标签不意味着原始标签从文件中被擦除。
- `data/<scene>/native_admission.jsonl.gz`：逐原生线段的真实源端点、准入/拒绝和约束接触记录。
- `data/<scene>/source_polygon_overlaps.json`：原始源面正面积重叠对象对；重叠不自动等于重复，也不作为自动过滤依据。
- `data/<scene>/historical_route.json` 与 `historical_variants.json`：真实历史运行 ID、输入、几何、文件 SHA256；可切换变体被限制在相同 start/door/purpose。
- `data/<scene>/input_receipt.json`、`historical_code_receipt.json`、`baseline_receipt.json`：固定 R1 ZIP → 成员 manifest → 实际只读文件的身份链。
- `current_graph_inventory.json`、各场景 `current_graph.json` 与 `current_graph_object_lineage.jsonl.gz`：已有 R1 B3 的 source-complete 面、完整面overlay统计、精确接口、候选/已接受接缝、portal与原始来源ID。博物馆/图书馆来自真实APP结果，展览/上海中心来自真实机制请求；机制请求不会被改称APP登记门任务。武康/新世界城未找到正式current结果，图实例化状态为未知，各图边/接口数量为null，不用0冒充未知。全局边未导出时明确NOT_EXPORTED。
- `development_source_identity.json.gz` 与 `development_extents.json`：空间泄漏检查使用的完整源 ID 集与裁片范围；不能把六个重叠裁片当作六个独立验证地点。

## 不能由本轮证明的事项

没有重建完整全局可视图，因此 C 不是完整 VG 的所有边可视化。旧结果的全局节点/弧数、完整面overlay数量与持久化seam delta分别登记，不能直接相加成唯一全局图。C可点选旧真实精确接口与接缝；面内VG边未导出时不画造边。原生准入回放用于追踪语义，不是新的算法效果实验。

导出的有效几何只代表被历史解析器成功解析的对象。未解析关系、缺失节点、未闭合环和裁片外成员分别保留未解析状态，不能把“导出几何无 invalid”扩写成所有原始环都已被证明正确。精确几何重复及正面积重叠均保留源 ID，不默默合并。

地图不能证明现实公共通行、开门状态或未登记障碍。六个开发裁片已被反复使用；本轮没有验证、冻结或读取任何盲测标签。道路缺失面、宽度、层级与权限字段的未知状态仍然保留。

旧适配器对54个源几何不可解析对象生成了UNKNOWN派生包围盒：博物馆1、新世界城1、上海中心52。B以玫瑰色虚框如实显示这些导入变换，并可点选查看原始对象ID和失败依据；A不把它们当作源面补画。另有可解析源线转为语义面等23处阶段几何差异，B使用适配器实际几何，D使用旧诊断实际几何。未解析的源几何仍是未解析，不因有保守包围盒而得到真实性证明。

源数据及派生地图按 OSM/ODbL 单独管理，本地审核不构成首次公开发布授权。仅自有审计包装代码可提交首次公开许可审查；旧规划器、原始数据、坐标和生成地图不在首次公开清单中。
