# 已知入口整链R1验收清单

## 核心业务（不能用技术测试替代）
- [ ] 用户从页面发起一个非历史答案查询，后端真实求路，有request_id与新运行记录。
- [ ] 同门换起点、换适用门、切换F0/F1能正确计算；旧结果不覆盖新输入。
- [ ] 当前场景/覆盖、原起点与接图点、目标门身份和用途在页面可见。
- [ ] 结果显示连续性、精确门点残差、原生/派生/假设路段、几何长度及广义代价。
- [ ] exit可作到门外诊断，不能被推荐为入馆入口；无门场景不生成代理门。
- [ ] 有失败地图和可理解原因；没有强行接通或只输出NO_ROUTE。

## 必须保留的比较与诊断
- [ ] 七条固定失败逐条有证据，不换题、不合并成“7个建筑”。
- [ ] 已有通道、约束导出、端点绑定为通用规则，无场景放行特判。
- [ ] 25父任务/41查询及自然北门、南门、草地回归；修复导致的变化逐项说明。
- [ ] F0/F1相同无权图；有限代价不改变可达集合，不把代价当米数。
- [ ] 控制遮蔽预测与真实应用输入、缓存和指标分离。

## 实际工程与审查
- [ ] 一个规划核心供CLI/HTTP/UI调用，部署不需要原Windows绝对路径或秘密配置。
- [ ] 新查询验收禁用路线答案缓存，记录真实solver执行；允许合法预处理缓存。
- [ ] 共同图不被跨请求污染，起点/目标变化与并发结果不会串线。
- [ ] 只监听127.0.0.1，有真实启动地址与本任务停止方式，不杀无关进程。
- [ ] 冷启动/预处理/热查询/验证耗时分开，资源与真实未测项如实记录。
- [ ] 地图保留建筑、道路、草地、广场、步道和限制面，不只有抽象图。
- [ ] 用户自然语言审核，无强制评分表。
- [ ] 最终包CRC/清单/哈希核验，空目录启动并计算至少一条新请求。
- [ ] 作者、独立审核、用户验收、现场验证和教师提交分开。

若只有静态回放、只有后台脚本或只有失败审计，整体只能PARTIAL。合理未接通不自动阻断整链工程验收，但已知错误放行不能用免责声明代替修复。
