# S 阶段作者核查

## 错误定位与复现

冻结 `inputs/rev1/src/native_adapter.py` 的 `Source.obstacles` 将 `landuse=grass`、水体和其他背景面统一标成 `AREA`。同包 `src/route_measure.py` 的 `path_conflicts` 对任何穿入该面的步道执行相同的冲突判断，`src/audit_native_prefix.py` 的 `native_view` 据此删除原生图边。北门 R1 的前段直接使用这套过滤器。

S0 和 S1 从同一裁片、冻结原生路网筛选及同一起终点构图。两者共享硬障碍和通行规则。唯一切换项是背景草地与明确登记的原生步行通道重叠时的判定。S1 保留符合规则的原始线、原生节点和方向，逐边记录 `MAPPED_PATH_OVER_LANDCOVER`。面内其余空间仍按原草地地表处理。黄陂北路 `way/654297629` 和 `way/1074409256` 均为 `highway=tertiary`，两种图中各有 0 条有向边。
