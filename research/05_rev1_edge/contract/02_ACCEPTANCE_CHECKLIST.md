# R4-REV1验收清单

该清单用于核验执行覆盖，不预填任何通过结论。

| 检查 | 必须给出的证据 | 不能代替它的东西 |
|---|---|---|
| 基线身份 | 固定ZIP/源文件哈希及六场景历史回归 | 目录名、口头声称只读 |
| 真正面派生 | 没有同位置原生线的计算边与父面ID；合成可达/拒绝反例 | 把已有线重新计数 |
| 南侧接入 | 三个外接点、边缘带网络和原南门之间逐段路径或明确断点 | 画一条没有入图的示意线 |
| 允许域约束 | 面/洞/障碍/屏障检查、连续折线与端口关系 | 只检查端点、稀疏采样或自己输出的PASS |
| 北侧解释 | 北面实际运行、到门外状态、约8米缺口、exit入馆角色分列 | 从主分母删掉后不再分析 |
| 门坐标与数值 | 原坐标不变，末点残差与未支持长度 | 吸附、截断或画图补线假装到达 |
| 机制比较 | 主设置、1/5米敏感性、撤除派生层消融、适用病例与失败 | 只报最短或成功的路线 |
| 双路径身份 | OSM增强实际run与Geoapify历史结果分列 | 共同schema通过就称双方均有图增强 |
| 地图可读性 | 有建筑、南北广场、内环、已有步道的真实底图及同视野对照 | 只有节点和抽象流程图 |
| 用户验收 | 可直接自然语言反馈的页面与问题 | 代填评分、强制重新打分 |
| 外审与复现 | 审核输入版本、逐段独立检查、从固定ZIP重放 | 子代理结束或CRC通过等同科研通过 |

有效负结果可以通过“研究过程与证据”验收，但不升级成“方法有效”。0新增时必须证明新面派生算法实际被运行，并定位允许域断裂或障碍，不能沿用旧的无原生线前置拒绝。
