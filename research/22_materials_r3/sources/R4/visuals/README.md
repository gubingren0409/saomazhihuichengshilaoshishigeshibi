# R4 证据地图

离线打开 [交互页](index.html)。页面不读取网络，也不请求服务端。地图由冻结 OSM 裁片和 R4 机器产物渲染。向量图内用 WGS84 原始要素投影到 EPSG:32651，细节视野围绕研究对象，完整视野包含冻结起点和实际留存的路线。米制比例尺随导出的 SVG 保留。

- 用 B0–B3 查看同视野的路线和拓扑。历史托管折线、历史本地接近诊断、冻结 B0 回放和登记入口主实验各有独立图层或表格。
- 点击边界、接点或入口查看原生 ID、状态、距离和判定。B0 分量色供定位，精确分量 ID 可点击相应线段核对。
- 原始开放空间面的填色显示地物范围。已在 B0 的原生步行边和因层级被拒绝的边分别绘制。
- 已登记入口与原始代理点各有单独符号。无路线样本保留原始网络位置和末端差，作为缺段诊断。
- 生成路线线条来自冻结路由和机器结果。所有 SVG 元数据保留场景、视野、变体、图层、原始机器几何文件和 SHA256。

在 R4 根目录执行：

```powershell
python -X utf8 -B -m src.build_visuals --render
python -X utf8 -B -m src.build_visuals --browser-only
```

第一条使用本机 Edge 离线重建图件与浏览器收据。第二条可从已解包的审查目录复核交互，不写入固定页面。作者技术验收与独立核验、用户人工验收、现场核验分别记录。
