# R4旧规则与本轮修订规则

依据：用户对“地图信息被弱化、南北门未连通”的质疑、`R4_MAP_INFORMATION_REVIEW.zip` 的源码/几何复核，以及用户要求下一轮执行包。
本文件是本轮任务说明，不修改旧事实或项目长期协议。详尽定义、参数与边界以新 Prompt 为准。

| 旧条件/旧处理 | 本轮明确替换 | 不变的保护 |
|---|---|---|
| 有步行面但没有同位置原生步行线，不允许正式建边 | 源步行面语义、完整几何、真实接点与障碍约束可支持条件性派生边 | 不能称其为原生道路或现场真值 |
| B1/B2只重筛原生线 | 真正运行面内外环边缘带的计算网络；已有内部线只是保留输入 | 不在整个面上无限制自由穿越，不跨洞/墙/水体 |
| 与建筑共边就整段否定 | 在面一侧处理净空，已登记门允许仅终端边界接触 | 不穿建筑内部，不移动门点，不挖墙 |
| 博物馆只选择南面，其余上下文 | 南面作为主实验，北面也进入源域与外部可达性诊断 | 研究区域仅既有冻结裁片 |
| exit从入馆分母排除后不算路线 | 到门外与允许入馆分开；exit仍作门外诊断 | 不因为更短把exit升级成可入馆门 |
| 约8米相邻关系易被混为拓扑接入 | 单独计算、显示可达位置与未支持缺口 | 不放大snap、不用数值容差吞掉间隙 |
| 缺少现场证据导致所有计算被阻断 | 对明确步行面可做地图条件建模，现场状态仍UNKNOWN | 不将地图条件可达等同实际公众通行 |
| Geoapify与OSM共同接口被理解为图增强两边都做过 | 本地图增强实际运行；Geoapify保留历史服务基线及可用字段检查 | 不虚构托管内部路网、不新增请求 |
| 没有填写新CSV就认为用户还未反馈 | 原有自然语言意见登记为会话来源；新一轮仍接受自然语言验收 | 不代填分数、不伪造UI原件或时间戳 |

## 预设试验参数的身份

主带宽3米、1/5米敏感性、0.25米障碍保守余量及有限离散参数是本轮提出并随任务发送授权的模型设置，**不是从复核包测得的通行宽度，也不是规范推荐值**。原复核数据仅证明对象关系和旧实现限制，没有证明修订模型一定成功。

## 明确不变

未标记入口生成 `DEFERRED_PENDING_USER_DESIGN`；六个既有场景；原始门坐标；历史结果只读；不新增外部地理数据、不付费、不训练、不改黄陂北路规则、不启动R5。
