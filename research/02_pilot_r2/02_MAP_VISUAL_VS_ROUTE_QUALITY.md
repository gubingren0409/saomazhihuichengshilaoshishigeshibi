# 地图视觉与路线功能的分开评价

场景只有上海博物馆人民广场馆一栋。近景 P-872C 和上下文 P-2CAE 是同一建筑的两个视野。双侧原图保留原始图幅、尺度和署名。对照用首轮真实底图，图注观察来自用户，不从静态图推断路由权重。 [原底图并排](figures/figure05_visual_comparison.png)

## 视觉信息

**OBSERVED_USER** 用户认为 A 的建筑与间隙色差比 B 小，但视觉上仍能辨认。B 的道路或建筑名称文字更多。用户指出两图都没有画出北门，并认为南侧广场的可步行性没有充分表达。原文中关于标签阈值、广场识别与错门的原因是用户提出的解释，保留为观察后的假设。

**OBSERVED / RECOMPUTED** 源数据有广场面和南侧 `entrance=main`，北西侧还有独立的 `entrance=exit` 标记。未在原图上清楚标注某个门，不能推出源数据无该点。两图视野已同尺度验证，但没有独立给任何一侧追加人工可读性分数。

## 路线功能

**RECOMPUTED** 两条折线在同一共有步道出发，初段分别采用几何捷径和北侧绕行，后续在同一处人民大道过街汇合。已知本地折线可追溯至源步行边，托管折线可与原生几何对齐，内部通行决策仍未知。绘制的两条线没有穿过目标建筑内部。这里的源形状检查不覆盖未登记障碍、不同楼层或现场路况。

**OBSERVED / RECOMPUTED** 本地固定入口路线未通过 35 米门槛。Geoapify 虽然 HTTP 200，两条已画折线都在离入口约 55 米的路网位置停止。路线折线与图面可以在视觉上对齐，同时仍缺建筑最后一段接入。图上的接入诊断线仅显示几何距离。 [分层追溯](figures/figure06_layers.png)

**结论** 用户视觉总体偏好相同。路线功能检查发现两条线都有末段缺口，当前不足以形成独立的功能偏好或数据源选择。没有现场评估样本。
