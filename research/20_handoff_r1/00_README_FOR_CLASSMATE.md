# 科研材料交接说明

项目研究的是：步行导航到了建筑附近以后，怎样利用已登记门、步道和步行面，补上到门外接近位置的最后一段。这里收集的是已经实际完成的研究，不是要接收同学重新跑实验的工程交接。

解压后双击 **index.html** 即可离线阅读；**figures/index.html** 是可按轮次和关键词检索的真实图册。无需安装Python、启动服务、登录地图账号或访问原作者的C盘/E盘。Markdown正文、CSV/JSON指标和原图也都在包内。每个入选原文件保持原字节，来源和SHA256见 evidence/SOURCE_INDEX.csv。

本包提供项目介绍、系统与术语说明、历史时间线、逐轮实验记录、关键结果、负结果、能力限制、研究决策和真实图件。接收同学自行决定材料的使用方式；本包不包含PPT页数、逐页内容、演讲稿、故事线、答辩问答或设计建议。

## 阅读时必须保留的边界

- **条件路线≠现场可通行路线。** 缺标空间可能被规划器作为研究假设允许，但不因此成为原生地图事实。
- **已登记门≠已现场确认的公众入口。** 上海博物馆北侧node/6897145227是exit，仅作门外接近目标；南门node/6897141353是main，当前开放仍未核验。
- **地图对象更多≠业务路线更短。** 82个新增面、局部接口3/8→5/8与四业务路线不变可以同时成立。
- **最新馆体地图已经纠正。** 旧native窗口实际是馆体西北侧步道，不能当作博物馆门口路线；最新图显示way/161090899及原两门，但现实几何精度仍未独立验证。
- **开发证据≠独立泛化证据。** 六上海裁片共享源对象，候选发现成果已暴露，Validation/Blind未冻结。

以上逐项证据见 [关键结果](05_KEY_RESULTS_AND_FINDINGS.md)、[能力和限制](06_CURRENT_CAPABILITIES_AND_LIMITATIONS.md)与[结论—证据矩阵](evidence/claims.html)。

## 证据身份

`VERIFIED_SOURCE`：本轮查到实际文件与对应字段；不自动表示重跑原实验或现场验证。

`AUTHOR_REPORTED`：旧执行报告已有记载，本轮未独立核算对应底层数据。

`INTERPRETATION`：基于这些证据的研究归纳。

`UNKNOWN / NOT_VERIFIED`：缺证据或不能确认，保留未知。

原始文档中的旧状态、旧解释和本机路径均原样保留。它们用于追溯，不要求接收同学配置该路径；与最新纠错冲突时，以明确列出的后续修正关系为准，不将旧文档改写成“当时就已正确”。

## 分享范围

本包供同学私下理解研究，不是GitHub公开数据发布。OSM图保留OpenStreetMap署名与ODbL说明；Geoapify原静态图仅沿用旧审计中正常保存、人工课堂展示和审核传递的条件，不向CV/VLM/训练工具传图。私有高德原图、密钥、Cookie和受限源数据不包含。受限或未找到材料列在来源索引，不伪造替代物。
