PROJECT OVERVIEW

项目介绍

项目历史名称为《面向复杂建筑的目的地接入关系补全与可靠到达点选择》，当前PG1聚焦末段步行网络基础。问题发生在“已经接近目标建筑，但尚不知道怎样沿合理空间走到相应门外”的阶段：建筑中心点可能在楼里，道路接入点可能隔着围栏，广场虽在地图上有颜色却不一定进入路由图。这里的“最后一段”不是简单把两点连直线。C-PROBLEM

研究对象包括建筑身份、已登记入口/出口、线状步道、道路轴与共享街道假设、过街、广场等已登记步行面、限制与障碍，以及这些对象之间的接入关系。方法希望让“沿线走”和“在合法面内穿行”进入统一图，同时说明哪些段来自原生几何、哪些段由面内计算得到、哪些段只是缺标空间假设。

早期NYC工作主要回答已知登记EP与候选AP的关系排序和条件几何路径；Southampton/Gapwise主要用于登记入口参考恢复与质量审计。后续NAV-END探索开放地图截图和原型，再转向OSM与Geoapify对照、结构化线面衔接及已知门条件规划。不同数据域、任务和分母没有被拼成一个端到端成功率。L-NYC-MATCH L-NYC-CHAIN

目前实现的是开发场景中的条件已知门末段规划原型，以及若干局部机制。它还不是面向任意建筑名称、实时GPS、任意真实主门和当前公众权限的完整导航产品。未标记入口生成属于另一个问题；当前PG1与近轮空间恢复工作没有授权继续开展它，历史NAV-END候选实验也不能视为通用门识别已经完成。

项目保留两条地图路径：本地OSM结构化数据便于审查和构图，Geoapify提供托管地图与路线基线。二者共享OSM地理数据家族，不是两套独立地理真值；没有证据足以宣布一方普遍优胜。R-OSM-GEOAPIFY-PILOT-R3

SYSTEM CONCEPT AND MODULES

系统概念、输入输出与技术模块

目标系统与已实现部分

概念链为：目标建筑身份 → 已登记门与用途 → 合法地图起点 → 线状步行网络及过街 → 已登记步行面内部 → 必要的条件缺标区域 → 原门对应接近位置。每一段都带来源、约束和失败状态。

已知门原型已实现CLI、HTTP与地图交互：选择冻结场景、起点、登记门、用途和F0/F1后，后端真实调用统一求解内核，返回本次请求的路线与分段信息；历史验收禁止用旧路线答案缓存冒充新计算。本次材料整理没有再次启动这些求解或验收。M-E2E-APP

地图到图的不同层次

  1. 源对象：原生node/way/relation及标签、几何、层级、权限。
  2. 适配与语义：把原线/原面解析为共同输入，保留失败和未知；道路轴不能改名为独立人行道。
  3. 约束与图准入：检查建筑、内环、花坛/草地、水体、围栏、权限、层级、净空和合法开口，再决定哪些线或派生边可入图。
  4. 图内求解：原生线、面派生边、已说明的条件边共同参与搜索；多个合法面接点由全图选择，不能只把旧路线画直。
  5. 结果说明：返回原门、原始与派生坐标、边序列、分段来源、长度/代价、假设段以及阻断原因。

源对象被发现、对象通过准入、图里可达、最终路线使用，是四件不同的事。完整步行面在取得合法多边形内计算穿行，仍是面派生段；F0缺标空间是另一种假设身份，不能混为一谈。M-CONNECT-82 M-CONNECT-MECH

F0与F1

F0在固定局部门前域内，排除已知不允许区域后允许缺标空间参与条件规划；未知事实仍然未知。F1使用完全相同区域、节点、边和接口，只提高假设段的有限代价。因而两者的可达集合应相同，路线偏好可以不同。假设代价不是现实风险概率，也不是安全保证。M-FREE-REACH M-FREE-COST

面内穿行与接口

FULL_FACE使用带洞合法多边形可见图，逐边检查完整线段；EDGE_BAND是历史3m边缘带表示。面线与面面衔接分别保留原生精确接点和条件小接缝，不将二维相交直接当作同层连通。已有合法过街仍按规则保留，没有新增自由横穿车道。

街区侧通道

R0保留旧道路轴/共享街道表示；R1利用原生步道和明确侧别；R2补充标明假设的缺标同侧通道。没有路宽时只研究带road_id、side、level的拓扑身份。图上的4m偏移是示意，不是实测人行道。沿街与跨街分开，不强制街区闭环。PG1-I06 PG1-I07

TERMS GLOSSARY

术语表

EP / EntrancePoint：登记入口点；数据中的位置参考，不自动等于当前真实物理门。

AP / AccessPoint：道路或外部网络的候选接入位置；已登记关联不证明两点间存在实际通路。

main / exit：main是主入口登记；exit是出口，本项目仅允许相应用途的门外接近。

原生步道：源数据已有步行线及其原始ID；与道路轴推断分开。

道路轴：道路中心线；不能直接改名人行道，也不能假定左右两侧可随处互通。

步行面：源中明确标记的可步行空间几何；内部仍需处理洞、障碍、权限、层级与接点。

面派生边：在已标合法步行面中通过计算得到的图边，不是实测轨迹。

条件假设边：在缺标空间按研究规则允许的计算边，未知事实不被升级。

F0 / F1：同图同域；F1仅增加假设段的有限代价，不改变几何准入。

EDGE_BAND / FULL_FACE：历史边缘带与完整合法步行面表示；是空间表示变化，非旧路线拉直。

R0 / R1 / R2：街区侧小试的轴线、源/明确侧别、条件侧道三变体；与其他轮次R编号不通用。

B0 / B1 / B2 / B3：CONNECTIVITY轮的冻结、源面补齐、精确接口、条件接缝四变体；旧R4同名B编号需看轮次。

图分量：在特定方向/层级/边准入下可达的图结构；二维相邻不代表同分量。

SCHEMATIC：示意几何偏移；不能用来报告真实位置、净空或精确步程。

可达 / 返回路线：对应固定图和求解合同成立；不能直接解释为现实可走。

参考外未证实扩张：预测允许域超出已知参考，可能有用也可能不合理；不一概当错误或真值。

盲测 / 已暴露候选：盲测须在方法冻结前隔离；已经看过的地点或标签不能重新称独立盲测。

SHA256 / CRC：SHA绑定文件字节身份；CRC检查ZIP内容损坏；均不证明科学结论或现场真实。

独立技术审核 / 人工验收：前者是另一个实际审查上下文的有限核验；后者仍由用户作自然语言判断，不能互代。
