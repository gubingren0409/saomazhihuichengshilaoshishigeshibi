# 四业务端点诊断地图

打开本目录的 `index.html` 可离线阅读；本机只读服务入口为 `http://127.0.0.1:53451/`。服务不提供求路POST接口，不会消耗本轮8次正式替代求路预算。

四张卡片分别是南门、北出口近起点、北出口远起点、图书馆登记门。主线来自R1四模式×F0/F1的32份原始响应，按原响应SHA绑定，不用R2的新最短路选择覆盖历史几何。R2替代线另画玫瑰虚线，并保留计算模式、方法与代价。

P是原始源面；Ω是冻结约束下的合法计算域。紫色虚线表示旧面集合未纳入的P，不表示任意扩张。公园、草地、建筑、水体和原生线来自同一冻结OSM，权限/线性限制的计算掩膜另标，中心线不代表道路宽度。

走廊5/10/20米只用于分析。为免密集接口遮盖底图，接口图层默认关闭；开启后仅画20米内或已采用的接口，关闭位置过滤可查看其他位置。点选表格会直接高亮该证据记录完整几何；接口表仍保留全部审计记录，先显示最近/筛选的500条。按原生ID或原因过滤后点一行即可定位，并查看完整对象详情。远面定位时仍显示冻结裁片中已取得的背景对象。

模式切换分别读取真实历史路线与面集合。接口的当前模式入图和可达性来自 `per_mode`，B3采用情况来自对应证据记录，其他模式仅有同ID出现时不自动认定这一节点绑定已采用；强制经过成本下界是B3完整图的机会审计，不冒充B0/B1/B2的实际路线。面级布尔表示有相应可达节点，不表示整个面的现场公众通行。

`source_context.json`保存真实源显示几何及历史路线。`map_payload.json.gz`是完整页面数据的无损gzip传输件，内嵌于HTML并由浏览器原生DecompressionStream解码，不访问外网。`map_payload_manifest.json`提供压缩/未压缩SHA；`audits/map_payload_integrity.json`逐行回拼所有接口原字段验证无损。完整逐接口CSV由实验角色保留，页面池化不删除证据。92096是接口×方法的证据记录数，不是唯一物理接口数。同一ID的不同节点绑定保留为独立数组记录，页面以case/method/array-index形成ui_record_key，选中和导出不按ID覆盖。

这是一份诊断器，不是新的导航产品。北门保留exit，仅讨论门外接近；权限和开放状态未知，现场通行未验证。用户穿行观察仍待确认，原截图精确请求仍未唯一绑定。
