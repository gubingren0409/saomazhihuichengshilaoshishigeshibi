# 双路径共同地图中间表示

本轮共同表示版本 `0.1.0`。机器合同为 [JSON Schema](schema/common_ir.schema.json)，实现见 [共同类型及适配器](src/common_ir.py)。它保存冻结请求、来源记录和各自可见的原生证据。入图决策、开放空间连接与路线选择留给下一阶段。

## 类型和口径

| 类型 | 核心字段与口径 |
| --- | --- |
| MapScene | 稳定场景 ID、经纬边界、EPSG:4326、来源时点、署名、请求视野、实测或留存视野。边界顺序为西、南、东、北。目标请求坐标和图面视野独立保存。 |
| BuildingFeature | 带命名空间的 OSM 原生 ID、建筑标签、几何、几何证据状态、原生字段与来源。 |
| PedestrianFeature | 道路、步道、过街、障碍与区域几何。保留 `highway`、`foot`、`access`、层级、相邻原生节点等已存在的标签。路面要素入选此列表只表达制图来源。 |
| OpenSpaceFeature | 广场、绿地等面积对象。单外环及完整内环按来源保留。缺环、拼接歧义或不可解析的几何记录为 `UNKNOWN`。显式 `foot` 或 `access` 标签记录为 `TAGGED_ALLOWED` 或 `TAGGED_RESTRICTED`，当前通行资格仍需单独核验。 |
| EntranceReference | 参考坐标、来源分级、是否选作请求目标、当前通行性和原生字段。参考可同时作为共享的任务背景。 |
| RouteRequest | 固定起点、请求终点、任务角色、步行模式、引擎原 profile 或查询类型、已知约束。 |
| RouteResult | 原状态、失败原因、分段几何、原始距离、单独复算距离及算法口径、返回起末点、两端 snap 和来源。保留本地正式尝试与另行生成的诊断。 |
| AccessCandidate | 本地返回的最近合格网络点、原生边、到请求目标的距离和证据。单独保留其候选身份。 |

坐标统一为 WGS84 经度在前。所有线段按源顶点顺序保留，保留断点。面积、楼层、方向和许可的未提供状态均为 `UNKNOWN`，数组为空可对应缺失来源或已观测裁片中的空集合，须结合 `feature_availability` 判读。图面比例尺和投影记录来自各自留存视野字段。

每个来源记录都用原文件相对路径、字节数和 SHA256 指向证据包。证据来源层区分 `OBSERVED`、`RECOMPUTED`、`INFERRED` 和 `UNKNOWN`。结构化原生字段保留在各类型的 `native_fields`，原图、裁片和响应文件可独立复核。技术复核可用 [入口脚本](src/build_common_ir.py) 和 [契约测试](tests/test_common_ir.py)。

## 两侧字段能力

| 字段组 | 本地 OSM adapter | Geoapify adapter |
| --- | --- | --- |
| 冻结场景和请求 | 冻结合同；原引擎 profile、已记录 snap 限值 | 同一冻结坐标作为任务输入；保留实际留存请求配置。未公开的内部 snap 限值为 `UNKNOWN`。 |
| 地图图层 | 可读矢量、要素原生 ID、标签与相邻节点 | 可保留实际静态地图和已校准视野。此接口未提供矢量图层或内部 OSM 快照时间。 |
| 入口 | 共享冻结参考和 OSM 证据等级，记录未实地验证 | 共享冻结参考仍标明其来自冻结场景。当前调用未得到独立验证的服务商入口。 |
| 路线及连接 | 冻结的本地结果、原生路径或已保留的 snap 证据 | 服务返回折线、原始距离及时间。服务内部图边、路由权重、snap 和入口身份保持 `UNKNOWN`。 |
| 开放空间与拓扑 | 原生面积/线成员和原生标签。本适配器不补面积内部连接。 | 静态图的颜色、文字和入口符号不生成矢量或拓扑。 |

同一组坐标、视野请求及步行意图可在两个 bundle 上进入相同的端点偏差、几何形状、失败分层等只读检查。数据齐全时可比较保留路线的同口径几何指标。全图建边、最短路和开放空间机制的共同运行需要相同级别、获许可的图输入。现有托管静态图与 Routing 接口未提供该输入。未来共同算法层可以接受两侧 bundle，并对同一机制输出已运行或缺字段原因。

## 真实输入复验

首轮上海博物馆走同一请求坐标，本地返回 `NO_ROUTE` 并保留独立的接近诊断，托管返回 `LIVE_ROUTE_RETURNED`。接口仍保留了 55 米末段的本地 snap 数据、托管折线终点和独立的南侧入口参考。OSM adapter 在真实裁片中保留 4,695 个建筑、3,610 个道路/步行/障碍对象和 164 个开放空间对象。对象数属于裁片库存，不等同于可路由边数。托管的三类矢量字段为 `UNKNOWN`。五个新增场景也已在实际产物上完成转换。共同子集保留 5 个配对请求、4 条本地返回路线、5 条托管返回路线及本地新世界城的无路由状态。托管各场景的向量图层及内部 snap 均为 UNKNOWN。逐场景见 [适配器回执](runs/common_ir/summary.json)。

```powershell
python -X utf8 -B -m src.build_common_ir
python -X utf8 -B -m pytest -q tests/test_common_ir.py
```

默认从 R3 包中的冻结 R1 工作副本及 R3 的场景、矢量和结果运行，网络请求为 0。完整 bundle 仅由留存输入生成，可离线重建。复验失败的先导任务仍保留在共同表示中。
